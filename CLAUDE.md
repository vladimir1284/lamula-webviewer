Panel admin (`pages/admin/`) con sesión HMAC propia (`server/api/admin/login.post.ts` + `server/middleware/admin.ts`) — **sin `adminToken` configurado (`NUXT_ADMIN_TOKEN`), el login queda deshabilitado (503)**, nunca un secreto por defecto. Rate-limit (`server/utils/rate-limit.ts`) en memoria de proceso — válido mientras el viewer corra como réplica única en el Swarm; si se escala horizontalmente hay que moverlo a un backend compartido.

## Qué es

Viewer web de productos NEXRAD Level III: reescritura de VestaWeb2 (Svelte 3 + Django) como **Nuxt 3**, corriendo como servidor Node en el Docker Swarm de `nexrad-l3-pipeline` (Cloudflare como DNS/CDN delante, no como hosting). Lee (solo lectura) los almacenes del pipeline: COGs AEQD calibrados en R2 (render cliente con OpenLayers `WebGLTileLayer` + `ol/source/GeoTIFF`, paleta como color ramp, vía URL pública) y Postgres (radares/rasters/fenómenos/VWP, leído directo por red interna del Swarm en las server routes).

## Reglas clave (ver docs/decisiones.md — no re-litigar sin motivo)

- El contrato de datos (radares/rasters/fenómenos/VWP/viento/rayos) lo posee nexrad-l3-pipeline (`db/pg_migrations/` de aquel repo). Sobre ese contrato este proyecto **jamás escribe** ni aplica migraciones; solo `SELECT`. **Excepción (decisión 39)**: `viewer.*` (schema propio, `db/viewer_migrations/`) es dominio de este repo — ahí sí se escribe (feedback de usuarios) y se migra. Nunca mezclar: tablas del pipeline siguen solo-lectura, sin excepción.
- Paletas y catálogo rico de productos viven **en este repo** (módulos TS por `product_code`), no en la base.
- Radar-agnóstico: `radars.proj4` se registra tal cual; nada hardcodeado.
- DAL con adaptadores live (Postgres directo/R2 por URL) y fixture (grabaciones + COGs golden) — todo lo de arriba es agnóstico a la fuente.
- Stack: Nuxt 3 (preset `node-server`, contenedor en el Swarm), **XState v5 + `@xstate/vue`** (decisión 18 — todo el estado de UI, URL como fuente de verdad; ver `docs/maquinas-estado.md`), Tailwind, PrimeVue v4 unstyled, `@nuxtjs/i18n` (es+en), OpenLayers ≥ 9 + proj4, Vitest + Playwright. Pinia sigue instalado (módulo Nuxt cargado) pero sin uso — el estado de UI vive en XState.
- Calibración raster: `físico = nivel · value_scale + value_offset` (niveles ≥ 2); 0 = nodata, 1 = range folded.
